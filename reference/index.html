04 / SAP

Transactions.

9 codes

  • ZPIQ_REP_MOD_SPARGet SPAR students per course
    Academic session (P1=100, P2=200, P4=400, P5=500) + course code → Execute → scroll right
  • ZPIQ_REP_STUD_SPARGet ALL MSP SPAR students
    Execute → find student → scroll right for details. Use when individual accommodation is unclear
  • ZPIQ_ATT_SHEETGenerate attendance sheets
    Event type * → Enter → select exam/course → change columns 12→1 → Execute → saves to C:\temp
  • ZPIQ_EXPORT_APPRExport grading sheets to Excel
    Course code + AY + period. Do NOT tick 'Exam Only'. Fill appraiser + appraisal date
  • ZPIQ_IMPORT_APPRImport completed grades from Excel
    Select file from DESKTOP (not server). Always run with 'Test' ticked first, then untick for real run
  • ZPIQSMFU_CALCCalculate and publish final grades
    Course code → Students → Attendance → Grade Supervisor → Final Result → select all → calculator → Accord → Block → Save
  • ZPIQSTFUUpdate single student grade/attendance
    Student number → AY + period → double-click course → adjust → Grade Supervisor row → Final Result → calculator → Accord → Block → Save
  • ZPIQ_MASS_EXAMRegister resit students
    AY = FIRST year of AY. Period = period course took place (NOT resit period). Course code → multiple selection → paste student numbers → upload → Execute → untick Test → Execute → Save. Creates an extra row per student file for the new final grade
  • ZPIQ_CALC_UCM_INDEX + ZPIQ_UCM_GRADESGPA calculation + transcript update
    Run after final grade calc: GPA against programme 7503, then transcripts. Exchange students run under MSP/EP, not 7503. Portal status 'Booked' = no first-attempt grade entered yet (e.g. additional assignment still owed); 'Failed' flips to 'Completed' ~a day after the SAP update. Canvas/EleUM changes NEVER sync to SAP — grade changes must be emailed to ESD or they sit unprocessed
05 / DOGMA

Key rules.

non-negotiables

Grading.

  • All grades on a scale of 1–10, rounded to 1 decimal (nearest decimal)
  • Grades below 5.5 = fail on transcript
  • ⚠ CRITICAL: 5.45–5.49 rounds DOWN to 5.4 (FAIL). Do not round up to 5.5
  • ⚠ Bounce back any submitted 5.5 and ask the CC to confirm it is 'a solid 5.5' (not a rounded 5.45-5.49)
  • Grades below 1.0 round UP to 1.0 — the scale starts at 1.0
  • SAP format: one decimal, COMMA separator (7,5), grades in 0.10 steps — SAP rejects 9.12-style values
  • No participation or missing partial assessment = NG (not graded). NG does NOT itself bar the resit
  • ⚠ NEVER register a real pass as 5.4 to force a resit (some coordinators ask for this because SAP blocks resits after a pass). The BoE secretariat considers it near-forgery that would not survive a CBE appeal — refuse and escalate to the BoE
  • ESD/the exam office may NOT calculate, round, or edit gradebooks — the CC must send the recomputed final course grade, not a raw component mark (accountability rule)
  • Sufficient overall grade + attendance fail = fail on transcript
  • Attendance 70–85%: student may repair via additional assignment (one-time ever — see glossary)
  • CC deadline: 10 working days from Friday of exam week
  • ESD has 5 additional working days to process after CC deadline
  • Student Portal publication deadline: 15 working days from last exam date
  • Transcripts of all active students must be updated within 1 working day of final publication
  • Exchange students sit in SAP degree MSP/EP, not programme 7503 — an easy step to forget in the grade run

Exams.

  • Final exams are standard 2 hours (UM policy). No exceptions
  • All final exams printed by ANDIDRUK. No self-printing permitted
  • Exam carts must be at UM Sports 90 minutes before exam start
  • SPAR students are separate — different locations, different boxes
  • Students cannot ask content questions during exam — exam must be triple-checked before printing
  • Open book exam = paper documents only. No internet access
  • Formula sheets must be included in the exam (paper) or within TestVision (digital)
  • Cover sheet must be the first page of every paper exam
  • Every paper exam must have 2 blank extra pages at the end

Student entry.

  • Valid UM card OR official ID/Passport required. Scans and photos not accepted
  • Zero tolerance for lateness — doors close at exact start time
  • No food. Drinks in sealed bottle/cup with lid only
  • Electronic devices of any kind are not allowed (watches, earphones, phones, hats with electronics)
  • One toilet visit per 2-hour exam at UM Sports. Not in first/last 30 min. SPAR (PHS, UNS50): up to 2 visits
  • Students may not leave before 30 minutes after start of exam
  • No papers of any kind may leave the exam hall
